# CMS137's flip gate over the WHOLE Maui roster

Date: 2026-09-07. The `--subjects all` run the flip PR needs (issue #534; ADR-072 d6, ADR-074 d14).
MM-1 U3 ran the gate over the first 2,000 corpus patients, which is a smoke run — enough to show the
gate works on the real roster shape, not enough to be the flip's evidence. This is all 20,000.

**Nothing here routes cms137.** The flip is a reviewed workflow edit a person makes, it is sequenced
after cms2 and cms130 (ADR-072 D1), and the CY2027 final rule that decides whether measure 305 stays in
APP Plus is expected around November 2026. This document is the evidence that flip will cite.

## Command

```
WORKWELL_INSTANCE=maui WORKWELL_MAUI_CORPUS_SIZE=20000 \
WORKWELL_OFFICIAL_MEASURES=cms122,cms125,cms137 WORKWELL_RUN_CHUNK_SIZE=500 \
pnpm flip-gate --measure cms137 --subjects all --evaluation-date 2026-12-31
```

The routing variable is the gate's HYPOTHETICAL routing — it evaluates the measure as the flip would
route it, without any deployment routing it. `WORKWELL_MAUI_CORPUS_SIZE` and the chunk size are the
values the Maui workflows ship, so the roster is the one the deployment actually runs (ADR-074 d14),
not a fixture.

## Reading it

- **20,000 of 20,000 evaluated, 0 evaluation errors.** Every subject was scored; nothing fell out of the
  chunked evaluation, which is the failure the 2,000-subject smoke run could not rule out.
- **599 in the initial population (3.0 %).** Substance use disorder episodes are rare, and the corpus
  draws them at a rate meant to look like one. A number near zero would fail the gate under ADR-043's
  whole-roster refusal; a number near the roster size would mean the artifact was matching everything.
- **Both rates are alive and they disagree.** Initiation credits 231 of 599, Engagement 81. That gap is
  the measure's whole point and the reason ADR-074 reads every rate: 150 patients started treatment and
  did not stay in it, and a single-rate reading would call them compliant.
- **518 actionable against 81 compliant.** Worst-of-rates, so a patient compliant on Initiation and not
  on Engagement is actionable — 599 − 81 = 518, which is the arithmetic the bucket promises.
- **19,401 MISSING_DATA** is the out-of-population bucket, not a data problem: those patients have no
  substance use disorder episode this year, so the measure does not score them.

## Limits — read before citing

1. Synthetic corpus patients (ADR-075), not the pilot's real panel. The gate proves the artifact reads
   this roster's shape; it says nothing about prevalence in a real population.
2. Measurement year **2026**. The vendored artifacts are 2026-vintage and PY2027 needs the MM-1d
   re-vendor and a full re-gate — this run does not carry forward.
3. A gate reading is evidence FOR a flip, never the flip. The other preconditions (ADR-072 D1's
   sequencing, MM-1c's second-engine sweep — done for cms137 at 44/45,
   `CROSS_ENGINE_2026-09-06_CMS137.md`) are separate and some are still open.
4. The per-subject JSON is written to `backend-ts/.flip-gate/cms137-2026-12-31.json`, which is
   gitignored: it names 20,000 synthetic subjects and is regenerable by the command above.
