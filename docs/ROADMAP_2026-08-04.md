## 4. The verification model (this replaces "Cypress green")

The old bar was a single external pass/fail. The new bar is a **named set of checks, each with a stated
scope and a stated limit.** Nothing here yields a certificate; every claim must say who graded it.

**Why V4 matters more than a Cypress green would have.** `fqm-testify` and `deqm-test-server` both wrap
**`fqm-execution`**, the library we already run — comparing against them compares our engine to itself.
The Java `cqf-fhir-cr` stack is a genuinely separate codebase (different CQL engine, different data
provider). Running CMS's test cases through both and diffing converts *"our engine agrees with our engine"*
into *"two independently written engines agree on CMS's own test cases."* That is a **stronger** claim than
the retired bar would have produced.

**Accepted cost, stated:** V4 puts a JVM back into the **verification** path, which cuts against ADR-008's
direction. Accepted deliberately as a **dev-time oracle only** — never a runtime or packaged dependency.
`cqf-tooling`'s `ExecuteMeasureTestOperation` exists but its **CLI surface is undocumented**; budget for
driving it programmatically.

## 6. Corrections to the record (carried out by this change)

1. **"~2030" for CMS FHIR endpoints is not CMS-attributable.** → "no published date." (§1.3)
2. **"QI-Core STU7 = US Core 7 = WebChart's exact surface" is half right and misleading.** QI-Core v7.0.2
   (STU7, 2026-04-04) does align to US Core 7. But **CMS's shipping measure content is authored on QI-Core
   6**, and the ecosystem's forward direction is **US Quality Core 0.5.0 over US Core 6.1.0**
   (`dqm-content-cms-2025`). We have been aiming at a version the content is not on. → M-D0.
3. **"Cypress CVU+ is the verification bar"** — in `docs/STANDARDS_CONFORMANCE.md` and the `conformance`
   skill. → replaced by §4's set. Left stale, this is a gate that quietly enforces a retired goal.
4. **The supplemental-data gap was recorded as an independent second cause.** It is downstream of the
   identity short-circuit. → corrected in ADR-058 and the conformance matrix.
